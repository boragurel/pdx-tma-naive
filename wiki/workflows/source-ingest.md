# Workflow: ingest a paper or document

Status: settled
Last updated: 2026-10-12
Scope: shared
Copied from: Studies/wiki/workflows/source-ingest.md (2026-10-22)

Read when a paper, report or inherited document is added to the wiki.

## Procedure

1. Read the source in full. For PDF extraction see [[reading-files]].
2. Discuss key findings with Bora before writing anything.
3. Write a summary page in `wiki/sources/`, named `first-author-year`
   (`doldi-2022.md`); for a document with no author, a short slug and the year.
4. Create or update the relevant `wiki/entities/` pages for markers, cohorts,
   phenotypes or concepts the source bears on.
5. Add `[[wikilinks]]` across affected pages.
6. Update [[index]]; append one line to `log.md`.

`Sources/` is immutable: never edit, rename or move files in it.

## Notes

- A single source may touch several pages. Updating existing pages matters more
  than creating new ones.
- Where a source contradicts something already in the wiki, say so explicitly
  on both pages rather than silently overwriting.
- Inherited notes from an earlier incarnation of a project are not literature:
  their claims are checked against the data before being carried into wiki
  pages.
